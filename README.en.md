# ED Mining Assistant Console Releases

ED Mining Assistant Console is a local mining companion for Elite Dangerous.
It reads local game files and can use optional community data from EDDN and
Spansh for mining plans, Prospector guidance, market comparison, and run history.

## Downloads and Source

Binary releases are published in this release repository. The complete source
code is public at:

https://github.com/He11wind/ed-mining-assistant-console

Each tagged source release can be downloaded using GitHub's source archives.
Checksums supplied with binary packages should be verified before installation.

## Quick Start

1. Download the Windows x64 archive for the selected version.
2. Extract the complete archive.
3. Run `start-eddn.cmd` for live EDDN market updates.
4. Run `start.cmd` to use local data without the EDDN listener.

## Data Sources

- Local Elite Dangerous Journal, cargo, loadout, and market files.
- [EDDN](https://eddn.edcd.io/) community market messages.
- [Spansh](https://spansh.co.uk/) community body, ring, reserve, and hotspot data.

Community information may be incomplete, delayed, or incorrect. Recommendations
are estimates and do not guarantee prices, demand, routes, yield, or profit.
