# Release Di ED Mining Assistant Console

ED Mining Assistant Console e un companion locale per il mining in Elite
Dangerous. Legge i file locali del gioco e puo usare dati community opzionali
EDDN e Spansh per piano mining, indicazioni Prospector, confronto mercati e
storico delle run.

## Download E Codice Sorgente

Le release binarie sono pubblicate in questo repository. Il codice sorgente
completo e pubblico su:

https://github.com/He11wind/ed-mining-assistant-console

Ogni release sorgente identificata da tag puo essere scaricata tramite gli
archivi sorgente di GitHub. Prima dell'installazione e consigliato verificare i
checksum forniti insieme ai pacchetti binari.

## Avvio Rapido

1. Scaricare l'archivio Windows x64 della versione scelta.
2. Estrarre l'intero archivio.
3. Avviare `start-eddn.cmd` per gli aggiornamenti mercato EDDN live.
4. Avviare `start.cmd` per usare i dati locali senza listener EDDN.

## Fonti Dei Dati

- File locali Journal, cargo, loadout e mercato di Elite Dangerous.
- Messaggi mercato community di [EDDN](https://eddn.edcd.io/).
- Dati community di [Spansh](https://spansh.co.uk/) su corpi, anelli, riserve e hotspot.

I dati community possono essere incompleti, ritardati o errati. Le raccomandazioni
sono stime e non garantiscono prezzi, domanda, rotte, resa o profitto.
